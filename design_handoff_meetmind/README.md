# Handoff: MeetMind — macOS menubar-приложение для записи встреч

## Overview
MeetMind — утилита в menubar macOS: записывает рабочие встречи (микрофон + системный звук одновременно), локально расшифровывает через Whisper и присылает фоллоу-ап в Telegram/Obsidian. Ключевая ценность — **всё на устройстве, ничего не уходит в облако** (кроме opt-in «Claude-бустера»), и дизайн это подчёркивает: бейджи «Локально · Whisper», замочки, явный красный индикатор записи.

Дизайн покрывает: 4 состояния menubar-иконки, дропдаун-меню (recording + idle), онбординг из 4 шагов, окно «встреча обработана». Всё — в тёмной и светлой теме.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, созданные в HTML** (`MeetMind UI.dc.html`). Это прототип, показывающий целевой вид и поведение, а НЕ production-код. Задача — **воссоздать эти макеты в целевой среде** (для macOS menubar-утилиты естественный выбор — SwiftUI + AppKit: NSStatusItem, NSPopover/NSMenu, NSVisualEffectView), используя её паттерны. Если среда ещё не выбрана — SwiftUI рекомендуется.

HTML имитирует нативные материалы macOS: вместо `backdrop-filter: blur(40px) saturate(180%)` используйте `NSVisualEffectView` (material `.popover` / `.hudWindow`), вместо ручных цветов — семантические `NSColor`/SwiftUI-эквиваленты, где указано соответствие.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы и копирайт финальные. Воссоздавайте пиксель-в-пиксель, но через нативные механизмы (SF Pro сам подставится как системный шрифт; SVG-иконки замените на перечисленные SF Symbols).

## Interactions & Behavior (микро-анимации)
- **Menubar recording**: точка пульсирует scale 1→1.3 + opacity 1→0.45, 1.2s ease-in-out ∞; таймер тикает 1 раз/с без анимации (tabular-nums — цифры не прыгают).
- **Processing**: кольцо вращается 1s linear ∞; дуга растёт с прогрессом транскрипции.
- **Смена состояний иконки**: crossfade 200ms. Error-бейдж появляется scale 0.5→1 spring + один мягкий подскок.
- **Меню**: открывается из иконки scale 0.97→1 + fade 160ms spring. Уровни 30fps, пики затухают 300ms. Кнопка записи: hover затемнение, active scale 0.98; иконка ● морфится в ■ 150ms при старте записи.
- **Тоггл Claude**: пружина 250ms; при первом включении — лист-подтверждение, что именно уйдёт в облако.
- **Онбординг**: переход шагов — слайд 24px + fade 250ms ease-out; чип «✓ Разрешено» появляется scale 0.8→1 spring после гранта; точки прогресса — заливка 200ms.
- **Окно фоллоу-апа**: всплывает у menubar fade + translateY(−8px) 220ms ease-out; секции каскадом с задержкой 40ms. Чекбокс: заливка 150ms + галочка stroke-draw 200ms + лёгкий strikethrough строки. «Переслать» после клика морфится в «✓ Отправлено» на 2s (spring по ширине), Esc закрывает.
- **Хоткей**: ⌘⇧R — глобальный старт/стоп записи.

## State Management
- `recordingState`: idle | recording(startedAt) | processing(progress 0–1) | error(message)
- `micLevel`, `systemLevel`: 0–1, live при записи (и на шаге 2 онбординга для проверки)
- `currentMeeting`: название (авто из календаря/времени) + таймер
- `recentMeetings`: последние 3 — {title, status: sent|transcribing(progress)|exportError, timestamp}; retry по клику на ошибку
- `claudeBoosterEnabled`: bool, default **false** (opt-in)
- `permissions`: microphone, screenAudioCapture — granted/denied
- `telegramLink`: none | pending(code) | connected(chat)
- `onboardingStep`: 1–4, пропускаемые шаги 3–4

## Assets
Внешних ассетов нет: все иконки в макете — инлайн-SVG, в реализации заменяются на SF Symbols (см. таблицу выше). Логотип Obsidian взять из их brand kit. Обои на фоне макетов — презентационная подложка, в приложение не входят.

## Files
- `MeetMind UI.dc.html` — единый холст: блок 3a (экраны 05–06, центр наблюдения) сверху, базовый блок 1a (экраны 01–04) ниже. ## Состояния и данные (экраны 05–06)
- `meetings`: [{title, date, duration, status: delivered|processing(progress)|error(message), sinks: [telegram|obsidian × ok|failed], engine: local|claude, actionItemsCount}]
- `searchQuery` + результаты: [{meetingId, source: transcript|summary, timecode?, snippet, matchRanges}] — FTS5 по транскриптам и саммари
- `pipeline` per meeting: recorded → transcribed(progress) → summarized → delivered; каждый шаг {timestamp} | {error: message}; retry на упавшем шаге
- `transcript`: [{timecode, speaker, text}]; клик по таймкоду — копирование

## Микро-анимации (экраны 05–06)
- Окно библиотеки открывается из меню scale 0.98→1 + fade 180 ms; дневные группы каскадом 40 ms; hover строк 120 ms.
- Поиск live с debounce 150 ms; список ↔ сниппеты crossfade 150 ms; подсветка слов fade 120 ms; чипы spring 200 ms; счётчик crossfade 150 ms.
- Табы: crossfade + слайд 8 px 200 ms, активный сегмент едет spring 250 ms; секции фоллоу-апа каскадом 40 ms.
- Таймкод: клик → вспышка подсветки строки 300 ms + тултип «Скопировано» 1.2 s.
- «Пересобрать»: меню scale 0.97→1 + fade 160 ms; при регене кнопка морфится в спиннер, секции перезаливаются каскадом.
- Пайплайн: шаги загораются слева направо по 150 ms, активный пульсирует; retry — иконка оборот 360°, шаг возвращается в спиннер.
