ОСНОВНЫЕ ФАЙЛЫ (УСТАНОВКА):
============================

1. manifest.json (36 строк)
   - WebExtension Manifest V2
   - Определяет permissions, content scripts, background, popup
   
2. content_script.js (598 строк)
   - Главный скрипт инжектируемый на meet.google.com
   - WSClient - управление WebSocket соединением
   - SpeakerObserver - отслеживание активного спикера
   - ChatObserver - отслеживание сообщений в чате
   - ParticipantObserver - отслеживание участников
   - MeetingLifecycle - начало/конец встречи
   - Функция initMeetMind() - инициализация всех компонентов

3. background.js (131 строка)
   - Background сервис расширения
   - Управление состоянием по вкладкам
   - Обновление значка расширения в toolbar
   - API для popup (getStatus, reconnect)

4. popup/popup.html (47 строк)
   - HTML интерфейс popup окна
   - Header с логотипом и названием
   - Status indicator - показывает статус подключения
   - Meeting info - информация о встречу
   - Action buttons - переподключение и помощь

5. popup/popup.css (243 строк)
   - Стили popup интерфейса
   - Тёмная тема (темный фон, светлый текст)
   - Gradient фоны (линейные градиенты)
   - Анимации (pulse для индикатора, hover для кнопок)
   - Responsive дизайн (ширина 350px)
   - Красивый scrollbar

6. popup/popup.js (131 строка)
   - Логика popup интерфейса
   - Получение статуса от background script
   - Обновление UI элементов в реальном времени
   - Автоматическое обновление каждые 2 сек
   - Обработчики событий кнопок

СОБЫТИЯ ДЛЯ WEBSOCKET:
======================

Format всех событий:
{
  "type": "event_type",
  "ts": "2026-04-13T10:30:45.123Z",
  "meeting_id": "xxx-xxxx-xxx"
}

События:
1. meeting_start
   - Встреча началась
   - Поля: type, ts, meeting_id

2. meeting_end
   - Встреча закончилась
   - Поля: type, ts, meeting_id

3. speaker
   - Активный спикер
   - Поля: type, name, ts, meeting_id

4. chat
   - Новое сообщение в чате
   - Поля: type, name, text, ts, meeting_id

5. participant_join
   - Участник присоединился
   - Поля: type, name, ts, meeting_id

6. participant_leave
   - Участник покинул встречу
   - Поля: type, name, ts, meeting_id

ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ:
=========================

✓ WebSocket соединение с автоматическим переподключением
  - Интервал переподключения: 3 секунды
  - Адрес: ws://localhost:8765

✓ Очередирование сообщений
  - Если соединение потеряно - сообщения ждут в очереди
  - Отправляются при восстановлении соединения

✓ MutationObserver для отслеживания DOM
  - Не требует polling'а
  - Эффективен по производительности

✓ Дедупликация событий
  - Спикер: максимум раз в 2 секунды
  - Чат: через messageId
  - Участники: через Set для O(1) поиска

✓ Несколько стратегий поиска активного спикера
  1. Поиск по data-requested-participant-id[aria-label]
  2. Поиск по video[data-participant-id]
  3. Поиск по aria-label*="is speaking"

✓ Полная обработка ошибок
  - Try-catch на каждом уровне
  - Graceful degradation если DOM элементы не найдены
  - Безопасное удаление наблюдателей

✓ Красивый интерфейс popup
  - Тёмная тема по умолчанию
  - Пульсирующий индикатор статуса (зелёный/красный)
  - Кнопки с hover-эффектами
  - Информация о встречу

✓ Отладка
  - Полное логирование в консоль браузера
  - Глобальные переменные для инспекции
  - Понятные сообщения об ошибках

ИНСТРУКЦИЯ ПО УСТАНОВКЕ:
========================

1. Запустить WebSocket сервер
   $ python3 example_server.py

2. Установить расширение в Firefox
   - Откройте about:debugging#/runtime/this-firefox
   - Load Temporary Add-on
   - Выберите manifest.json

3. Перейти на https://meet.google.com

4. Создать/присоединиться к встречу

5. События будут приходить на сервер

ГЛОБАЛЬНЫЕ ПЕРЕМЕННЫЕ ДЛЯ ОТЛАДКИ:
==================================

В контексте meet.google.com (открыть F12):

window.__meetmindClient
  .isConnected         - boolean, статус WebSocket
  .url                 - строка, адрес сервера
  .ws                  - WebSocket объект
  .messageQueue        - array, очередь сообщений
  
window.__meetmindClient.send(event)      - отправить событие
window.__meetmindClient.reconnect()      - переподключиться
window.__meetmindClient.getMeetingId()   - получить ID встречи

window.__meetmindObservers
  .speaker             - SpeakerObserver
  .chat                - ChatObserver
  .participants        - ParticipantObserver
  .lifecycle           - MeetingLifecycle

ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ:
=====================

// Проверить подключение
window.__meetmindClient.isConnected

// Отправить тестовое событие
window.__meetmindClient.send({
  type: "test",
  text: "Hello from MeetMind"
})

// Переподключиться
window.__meetmindClient.reconnect()

// Получить ID встречи
window.__meetmindClient.getMeetingId()

// Посмотреть очередь сообщений
window.__meetmindClient.messageQueue

ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ:
==============================

Проблема: "Демон не запущен" в popup
Решение:
  1. Убедитесь что python3 example_server.py запущен
  2. Проверьте что сервер слушает на localhost:8765
  3. Нажмите "Переподключиться" в popup

Проблема: События не приходят на сервер
Решение:
  1. Проверьте что вы на странице встречи (не на главной)
  2. Откройте F12 и посмотрите консоль на ошибки
  3. Попробуйте обновить страницу (Ctrl+R)
  4. Проверьте firewall/antivirus

Проблема: Имена участников как "Unknown"
Решение:
  1. Откройте инспектор (F12)
  2. Посмотрите структуру DOM видео элемента
  3. Сообщите селектор содержащий имя
  4. Расширение можно обновить с новым селектором
