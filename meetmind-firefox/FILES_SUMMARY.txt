ОСНОВНЫЕ ФАЙЛЫ РАСШИРЕНИЯ (готовые к установке):
================================================

1. manifest.json (36 строк, ~1.1KB)
   - WebExtension Manifest V2 конфигурация
   - Определяет permissions, content scripts, background script
   - Настройки иконки и popup интерфейса

2. content_script.js (598 строк, ~19KB)
   - Главный скрипт инжектируемый на meet.google.com
   - WSClient класс - управление WebSocket соединением
   - SpeakerObserver класс - отслеживание активного спикера
   - ChatObserver класс - отслеживание чата
   - ParticipantObserver класс - отслеживание участников
   - MeetingLifecycle класс - начало/конец встречи
   - Полная обработка ошибок и дедупликация событий

3. background.js (131 строка, ~4.5KB)
   - Background сервис для управления состоянием
   - Обработка сообщений от content scripts
   - Управление значком расширения в toolbar'е
   - API для popup (getStatus, reconnect)

4. popup/popup.html (47 строк, ~1.4KB)
   - Интерфейс popup окна
   - Статус индикатор с пульсирующей точкой
   - Информация о встречу (meeting ID, статус)
   - Кнопки управления и помощи
   - Минималистичный дизайн

5. popup/popup.css (243 строк, ~4KB)
   - Тёмная тема по умолчанию
   - Gradient фоны и анимации
   - Responsive дизайн (350px width)
   - Красивые кнопки с hover-эффектами
   - Кастомный scrollbar

6. popup/popup.js (131 строка, ~5.2KB)
   - Логика popup интерфейса
   - Получение статуса WS от background script
   - Обновление UI элементов в реальном времени
   - Auto-refresh каждые 2 секунды
   - Обработчики кнопок (переподключение, помощь)

ИТОГО РАСШИРЕНИЯ:
- Всего файлов: 6
- Всего строк кода: ~1186
- Полный размер: ~42.5KB

СОБЫТИЯ КОТОРЫЕ ОТПРАВЛЯЮТСЯ:
=====================================================================

Формат события:
{
  "type": "event_type",
  "name": "Имя участника",
  "text": "Текст (только для chat)",
  "ts": "2026-04-13T10:30:45.123Z",
  "meeting_id": "xxx-xxxx-xxx"
}

События:
1. meeting_start - Встреча началась
2. meeting_end - Встреча закончилась
3. speaker - Кто-то говорит (с именем спикера)
4. chat - Новое сообщение в чате (с именем и текстом)
5. participant_join - Участник присоединился
6. participant_leave - Участник покинул встречу

=====================================================================
КАК ИСПОЛЬЗОВАТЬ:
=====================================================================

1. Установить расширение:
   - Firefox > about:debugging > Load Temporary Add-on
   - Выбрать manifest.json

2. Запустить WebSocket сервер:
   $ python3 example_server.py

3. Перейти на https://meet.google.com

4. Создать/присоединиться к встречу

5. События будут приходить на сервер в реальном времени
