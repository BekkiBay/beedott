# MeetMind - Быстрый старт (5 минут)

## Минимальная подготовка

### 1. Установить зависимости

```bash
cd /Users/b.botirov/ИИшки/Супер\ ИИшные\ приколы/meetmind
pip install -r requirements.txt
```

### 2. Создать .env файл

```bash
cp .env.example .env
```

### 3. Добавить ваши ключи в .env

```bash
# Обязательные:
ANTHROPIC_API_KEY=sk-ant-v0-xxxxxxxxxxxxxx
GOOGLE_CREDENTIALS_PATH=credentials.json

# Опциональные для Telegram:
TELEGRAM_BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
TELEGRAM_CHAT_ID=123456789
```

### 4. Скачать credentials.json для Google Calendar

1. Перейти в https://console.cloud.google.com/
2. Создать OAuth2 credentials (Desktop app)
3. Скачать JSON
4. Положить в папку meetmind/ как `credentials.json`

### 5. Установить BlackHole (если нужна запись аудио)

```bash
brew install blackhole-2ch
# Перезагрузить Mac после установки
```

## Запуск

```bash
python3 main.py
```

Если вы видите:
```
=== MeetMind Daemon готов ===
```

То всё установлено правильно!

## Первый тест

### Без встреч:

Программа просто будет мониторить ваш календарь каждые 2 минуты.

### Чтобы протестировать:

1. Создайте в Google Calendar встречу на 5 минут позже текущего времени
2. За 5 минут до встречи появится macOS уведомление
3. Нажмите "ГО" чтобы начать запись
4. Говорите в микрофон 30 секунд
5. Нажмите встречу в календаре и завершите её
6. Программа начнёт обработку автоматически

## Что произойдёт при обработке

1. Запись будет транскрибирована (может занять 30-60 сек)
2. Claude создаст структурированный фоллоу-ап
3. Фоллоу-ап отправится в Telegram (если настроен)
4. Файлы сохранятся в папке `sessions/`

## Папка с результатами

```
sessions/2024-03-15_your-meeting_uuid/
├── meta.json           # Метаданные встречи
├── enriched.json       # Полный транскрипт
└── followup.md         # Фоллоу-ап для чтения
```

## Если что-то не работает

### Bluetooth микрофон не виден

```python
# Проверить доступные устройства
python3 -c "import sounddevice as sd; print(sd.query_devices())"
```

Обновить в .env:
```
AUDIO_DEVICE_NAME=Your Device Name
```

### Google Calendar не подключается

1. Проверить что `credentials.json` в папке meetmind/
2. Удалить `token.json` если он есть
3. Перезапустить программу - появится браузер для входа

### Whisper слишком медленный

Измените модель в .env с `medium` на `tiny` или `base`:

```
WHISPER_MODEL=tiny
```

### Claude API ошибка

1. Проверить что API ключ правильный и актуальный
2. Проверить что интернет подключение работает
