# MeetMind — аудит и трекер исправлений

Аудит от 2026-10-02. Полная версия с объяснениями, диаграммой и обоснованиями —
в доке «MeetMind — полный аудит проекта»
(https://claude.ai/code/artifact/74261cc6-3853-4c63-95a8-d6867082408c).
Этот файл — рабочий чек-лист: отмечаем `[x]`, когда пункт исправлен и проверен
(тест или ручная проверка), и пишем в скобках, чем проверено.

Нумерация совпадает с докой: T — технические баги, P — продуктовые дыры,
C — уборка. Серьёзность: 🔴 критично, 🟠 высокая, 🟡 средняя, ⚪ низкая.

## Проверить вручную после фиксов

Приложение пересобрано с ad-hoc подписью, поэтому при первой записи macOS снова
спросит доступ к микрофону и записи системного звука.

- [ ] Запись хоткеем ⌘⇧R: старт, стоп, повторное нажатие во время записи её
  останавливает, а не обрывает (T9).
- [ ] ⌃⌥⌘X во время записи показывает подтверждение; «Продолжить запись»
  ничего не ломает (T8).
- [ ] Quit во время записи: встреча обрабатывается и приходит в Telegram (T10).
- [ ] Запись с AirPods: звук в транскрипте не искажён (T11).
- [ ] Календарь: macOS спросит доступ; запись во время события из Календаря
  получает его название и участников (P8).
- [ ] Уведомления: macOS спросит разрешение; клик по уведомлению открывает
  карточку встречи (P16).
- [ ] Библиотека: импорт кнопкой, переименование, «Хранить аудио», удаление
  с подтверждением (P8, P10, P13, P14).
- [ ] Google Календарь: аккаунт добавлен в «Системные настройки → Учётные записи
  интернета → Google» с галкой «Календари»; в меню MeetMind строка
  «Google Календарь подключён».
- [ ] Реальный звонок Google Meet по событию из Календаря: запись стартует сама
  через ~10 с, останавливается через ~1 мин после выхода. В Firefox отдельно
  проверить: долгий mute не обрывает запись.
- [ ] Перезагрузка Mac: MeetMind и демон поднимаются сами после входа.
- [ ] Mute: во время записи ⌃⌥⌘M, Fn+F5 или кнопка — в транскрипте нет твоих
  слов за этот отрезок, собеседники есть. Без записи Fn+F5 снова работает в
  других приложениях.
- [ ] Островок: напоминание за минуту до реальной встречи; «Записать» не
  уводит фокус из созвона; наведение раскрывает запись; на внешнем мониторе
  появляется сверху по центру; во время демонстрации экрана в Meet островок
  прячется (проверить, что детект захвата экрана срабатывает).

## Продуктовые дыры

- [ ] P1 Нет автодетекта встреч (M5) — сначала «Идёт звонок — записать?».
  (Частично: Google Meet в любом браузере. Сигнал — «браузер пишет микрофон»
  (Core Audio по процессам, без разрешений и без чтения вкладок). Есть встреча
  с Meet в Google Календаре — запись стартует сама, без неё — уведомление
  «Записать?». Конец звонка — браузер замолчал на 60 с (или без микрофона
  15 мин) → автостоп. Ручную запись не трогает. Логика покрыта Swift-тестами
  `app/Tests/run.sh`; на реальном звонке не проверено. Zoom, сон и back-to-back
  из M5 — не сделаны.)
- [ ] P2 Локальная суммаризация не проходит memory-guard (10 GB) — всё делает Claude.
- [ ] P3 Claude включён по умолчанию (`opus`), хотя по спеке это opt-in.
- [ ] P4 Пишется весь системный звук (`.global`), а не только звонок (`.pid`).
- [ ] P5 Эхо без наушников задваивает реплики; «Спикер 1/2» вместо «Я/Собеседники».
- [x] P6 Пустая/случайная запись висит часами вместо авто-отмены.
  (Запись короче 10 с (`MEETMIND_MIN_RECORDING_SEC`) или пустая отменяется
  на стопе с уведомлением; «в записи не распознано речи» — сразу FAILED без
  8 ретраев. Тесты + вживую.)
- [x] P7 Время в UTC в заголовках и именах файлов.
  (Всё, что видит человек, — в местном времени, UTC+5; в БД остаётся UTC.
  Зону можно задать `MEETMIND_TZ`. Тесты + вживую: заметка `1914-…` в 19:14.)
- [x] P8 Нет названия и участников встречи (EventKit, переименование).
  (Название и участники берутся из Календаря на старте записи и уходят в
  промпт; встречу можно переименовать в карточке. Демон — тесты + вживую через
  API; календарь и UI — см. «Проверить вручную».)
- [x] P9 Задача без срока показывается как «asap»; `owner: null` выбрасывает
  улучшенный фоллоу-ап.
  («без срока» / «не назначен»; null и числа нормализуются, а не отбрасывают
  ответ. Тесты.)
- [x] P10 Retention молча удаляет аудио; 554 MB/час без сжатия.
  (Срок — `MEETMIND_RETENTION_DAYS`, 0 = не удалять; «Хранить аудио» в
  карточке; чистка раз в час; после транскрипции WAV сжимается в FLAC без
  потерь — ~30% размера, ~170 MB/час. Тесты + вживую.)
- [ ] P11 Нет «Скопировать фоллоу-ап» / отправки участникам.
- [x] P12 Пересборка саммари шлёт дубль в Telegram без пометки.
  (Новая версия помечена «🔄 Обновлённая версия фоллоу-апа (№N)» и уходит
  ответом на прошлое сообщение. Тесты + вживую.)
- [x] P13 Нельзя импортировать готовый аудиофайл.
  (Кнопка в Библиотеке и `python -m daemon.cli import <файл>`; файл
  конвертируется в моно FLAC 16 kHz и идёт по пайплайну. Тесты + вживую.)
- [x] P14 Нельзя удалить встречу из Библиотеки.
  (Кнопка в карточке с подтверждением; удаляются аудио, транскрипт, саммари,
  поиск и строки БД; заметки и Telegram остаются. Тесты + вживую через API.)
- [ ] P15 Нет метрик успеха (`scripts/metrics.sql`).
- [x] P16 Уведомления через osascript, клик никуда не ведёт.
  (Пока приложение запущено, уведомления показывает оно, клик открывает
  карточку встречи; без приложения — osascript, как раньше. Тесты; клик — см.
