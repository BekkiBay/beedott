# Handoff: MeetMind — Firefox-расширение для Google Meet

## Overview
Firefox-расширение MeetMind детектит начало созвона в Google Meet и управляет локальной записью встречи (микрофон + звук вкладки), которую ведёт нативное companion-приложение на macOS. Ничего не уходит в облако — запись и расшифровка локальные, и UI это постоянно проговаривает (замочки, «Локально, на вашем Mac»).

Поверхности: иконка тулбара (3 состояния), popup, тост при входе в звонок, overlay-индикатор на странице Meet (плашка + мини-панель), состояние ошибки «companion не запущен».

## About the Design Files
Файлы пакета — **дизайн-референсы в HTML** (`MeetMind Meet Extension.dc.html`), не production-код. Задача — воссоздать их в реальном WebExtension (Manifest V3 для Firefox): popup = `browser_action` popup (HTML/CSS/JS или Preact), тост/overlay/error-плашка = content script с Shadow DOM (изоляция от стилей Meet), иконка = `browserAction.setIcon` / `setBadgeText`. Связь с companion — Native Messaging или локальный WebSocket (см. архитектурную заметку внизу).

## Fidelity
**High-fidelity.** Цвета, размеры, радиусы и копирайт финальные. Стиль — Material в палитре Google Meet, чтобы UI не выглядел чужеродно внутри Meet.

## Screens / Views

### 1. Иконка тулбара (browserAction)
- **Idle**: монохромный waveform 17px, template — красится темой браузера.
- **Recording**: тот же waveform + бейдж «REC» (`setBadgeText('REC')`, `setBadgeBackgroundColor('#EA4335')`, белый текст).
- **Error**: иконка приглушена до 40–45% альфы, бейдж «!» на #F9AB00 (текст тёмный в dark-теме, белый в light). Тултип «MeetMind не запущен».

### 2. Popup (ширина 320)
Структура: шапка → контент → футер.
- Шапка (padding 12×16, нижняя граница): иконка 16px, «MeetMind» 13/700, справа статус-точка 7px + текст 11px: зелёная «Companion подключён» / жёлтая «Нет связи».
- Состояние **recording**: строка встречи (пульсирующая точка 9px #EA4335, название 13/500 + URL 11px secondary, таймер 16/700 #EA4335 справа); два уровня раздельно — «Микрофон» 66% и «Звук вкладки» 42% (лейбл 11px шириной 90px + бар 4px, radius 2, зелёная заливка); кнопка-пилюля 36px «Остановить запись» #F28B82 с квадратом-стопом 9px; тумблер «Записывать встречи автоматически» с подписью «Спрашивать не будем — просто начнём».
- Состояние **idle**: строка «Планёрка про бету / Звонок идёт · запись не ведётся», кнопка «Начать запись» red (#D93025 light) с кружком ● 9px.
- Состояние **disconnected**: центрированный столбец — жёлтый треугольник в круге 40px (tint 14%), «Companion-приложение не запущено» 13/600, объяснение 11.5px, кнопка «Запустить MeetMind» accent на всю ширину, подпись «deep-link: meetmind://launch». Кнопка записи недоступна.
- Футер: замок зелёный + «Запись и расшифровка — на вашем Mac» 10.5px + ссылка «Настройки» accent.

### 3. Тост при входе в звонок (content script)
Позиция: **top-center** страницы Meet (низ — запретная зона, там контролы Meet). Не блокирует клики вокруг (pointer-events только на самом тосте).
- Карточка #303134, radius 12, border rgba-white 0.1, padding 10–14: иконка 16px, «Начать запись встречи?» 13/600 + «Локально, на вашем Mac» 11px secondary; кнопки-пилюли 30px: «Да» filled #8AB4F8 (текст #202124), «Нет» и «Всегда для этого звонка» — текстовые accent с hover-tint 12%.
- Прогресс автоскрытия: линия 2px rgba(138,180,248,0.6) по нижней кромке, сгорает линейно за 10s; hover ставит на паузу. Esc = «Нет».
- «Всегда для этого звонка» запоминает код встречи (для повторяющихся созвонов).
- Вход: translateY(−12px) + fade 220ms ease-out.

### 4. Overlay на странице Meet
**Плашка (collapsed)**: высота 28px, pill radius 14, rgba(32,33,36,0.85) + blur 12; содержимое: drag-хэндл (6 точек, 40% альфы), пульсирующая точка 8px #EA4335, «REC» 11/700 letter-spacing 0.05em, таймер 11px #9aa0a6 tabular-nums. Позиция по умолчанию — top-right 16px.
- Drag свободный; отпускание примагничивает к ближайшему из верхних углов, spring 300ms. Позиция запоминается.
- Низ экрана — запретная зона. При старте демонстрации экрана плашка сама уходит в правый верхний угол.
**Мини-панель (expanded, клик по плашке)**: ширина 252, radius 14, rgba(32,33,36,0.92) + blur 16:
- Шапка: хэндл + точка + название встречи 12/600 (ellipsis) + таймер #EA4335 + шеврон-свернуть.
- Ряд кнопок: «Пауза» (rgba-white 0.1, иконка ⏸) и «Стоп» (#F28B82, текст #202124) — flex 1:1, высота 32, pill.
- Строка «Отметить момент»: звезда #FDD663 14px, подпись «попадёт в фоллоу-ап с таймкодом» 10.5px, кейкап хоткея «⌥M».
- Футер: замок green + «Пишем локально · мик + звук вкладки» 10px.
- Разворачивание: высота 200ms ease-out, плашка морфится в шапку; клик вне панели — сворачивает.
- «Отметить момент»: звезда вспыхивает scale 1→1.4→1 (350ms), вверх отлетает чип «+12:34» с fade. Пауза: точка перестаёт пульсировать, таймер мигает 1Hz.

### 5. Ошибка — companion не запущен (плашка на странице)
Ширина 300, radius 14, тот же blur-сарфейс, но border rgba(249,171,0,0.4):
- Строка: треугольник #F9AB00 16px, «MeetMind не запущен» 12.5/600 + «Запись этой встречи не идёт» 11px, крестик-закрыть.
- Кнопка «Запустить MeetMind» 32px pill #8AB4F8 с иконкой ▶.
- Подпись «meetmind://launch · подключимся автоматически» 10px по центру.
- Появление: лёгкое покачивание ±2° один раз. Не автоскрывается; крестик прячет до конца звонка. После deep-link расширение поллит companion; при коннекте плашка морфится в REC-индикатор + зелёная вспышка статуса 400ms.

## Interactions & Behavior — сводка
- Пульс записи: scale 1→1.3 + opacity 1→0.45, 1.2s ease-in-out ∞ (везде одинаковый).
- Material ripple на кнопках 300ms; hover — затемнение/подсветка тона.
- Уровни аудио: 30fps, данные по WebSocket/Native Messaging от companion.
- Смена статуса подключения в шапке popup: fade 200ms.
- Хоткеи: ⌥M — отметить момент (page-level, когда идёт запись).
- Честность записи: REC-индикатор нельзя скрыть, пока идёт запись, — только перетащить.

## State Management
- `companionState`: connected | disconnected | connecting (поллинг после deep-link)
- `recordingState`: idle | recording(startedAt, paused?) | error — синхронизируется с companion (source of truth — нативное приложение)
- `micLevel`, `tabLevel`: 0–1 live
- `meeting`: {title, meetCode, joinedAt}; детект по URL-паттерну meet.google.com/xxx-yyyy-zzz + DOM-сигналу входа в звонок
- `autoRecord`: bool (default false); `alwaysRecordCodes`: string[] — коды встреч из «Всегда для этого звонка»
- `overlayPosition`: {corner, offset} — persist в storage.local
- `markers`: [{timecode}] — «отмеченные моменты», уходят companion-у

## Design Tokens — прочее
Запретная зона для overlay/тостов: нижние ~96px страницы Meet (контролы) + правый нижний угол (чат/участники). Разрешённые зоны — верхняя половина, углы.

## Assets
Все иконки — инлайн-SVG в референсе; в расширении используйте Material Symbols (mic, tab_audio → volume_up, star, pause, stop, warning, lock, play_arrow) или собственные SVG. Иконка расширения — waveform (та же, что в companion-приложении), в 16/32/48/128px, template-вариант для тулбара.

## Files
