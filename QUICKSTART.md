# MeetMind - Быстрый старт

## Шаг 1: Установка WebSocket сервера

### Требования
- Python 3.8+
- pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

## Шаг 3: Установка расширения в Firefox

### Временная установка (для разработки)

1. Откройте Firefox
2. Перейдите на `about:debugging#/runtime/this-firefox`
3. Нажмите "Load Temporary Add-on"
4. Выберите файл `meetmind-firefox/manifest.json`

### Постоянная установка

1. Откройте Firefox
2. Перейдите на `about:addons`
3. Нажмите значок ⚙️ → "Install Add-on from File"
4. Выберите папку `meetmind-firefox/` и подтвердите

## Отладка

### Проверка логов расширения

1. Нажмите F12 в Firefox на странице meet.google.com
2. Откройте вкладку "Console"
3. Ищите сообщения начинающиеся с `[MeetMind]`

### Проверка WebSocket соединения

В консоли браузера выполните:

```javascript
// Проверяем WebSocket клиент
window.__meetmindClient

// Проверяем статус
window.__meetmindClient.isConnected

// Проверяем meeting ID
window.__meetmindClient.getMeetingId()

// Отправляем тестовое событие
window.__meetmindClient.send({type: "test", text: "Hello"})

// Переподключаемся
window.__meetmindClient.reconnect()
```

## Интеграция с собственным сервером

Вместо использования `example_server.py` вы можете создать собственный WebSocket сервер:

```python
import asyncio
import websockets
import json

async def handler(websocket, path):
    try:
        async for message in websocket:
            event = json.loads(message)
            print(f"Событие: {event['type']}")
            
            # Обработка события
            if event['type'] == 'speaker':
                print(f"Говорит: {event['name']}")
            elif event['type'] == 'chat':
                print(f"Сообщение: {event['name']}: {event['text']}")
            elif event['type'] == 'participant_join':
                print(f"Присоединился: {event['name']}")
            elif event['type'] == 'participant_leave':
                print(f"Покинул: {event['name']}")
                
    except Exception as e:
        print(f"Ошибка: {e}")

async def main():
    async with websockets.serve(handler, "localhost", 8765):
        await asyncio.Future()

asyncio.run(main())
```

## Частые проблемы

### "Демон не запущен" в popup

- Проверьте что `example_server.py` запущен
- Проверьте что не закрыт терминал с сервером
- Попробуйте нажать "Переподключиться" в popup

### События не приходят на сервер

1. Убедитесь что вы на странице встречи (не на главной странице Meet)
2. Откройте F12 и проверьте логи расширения
3. Проверьте что сервер слушает на `ws://localhost:8765`
4. Попробуйте обновить страницу встречи (Ctrl+R)

### "WebSocket отключено" в логах

Это нормально если:
- Сервер был перезагружен
- Произошел разрыв сети
- Расширение переподключается каждые 3 секунды

### Имена участников как "Unknown"

DOM структура Google Meet меняется. Если имена не работают:
1. Откройте F12 (инспектор)
2. Наведите на видео участника
3. Найдите элемент содержащий имя
4. Сообщите селектор чтобы обновить расширение
